Independent security assessments of the smart contracts supporting the XMAQUINA ecosystem.

## Genesis Auction & DEUS

The Genesis Auction Swap Contract and the DEUS Token Contract have undergone independent security audits conducted by Hashlock.

### Reports

- [Genesis Auction Swap Contract Audit](https://hashlock.com/wp-content/uploads/2024/10/XMaquina-Smart-Contract-Audit-Report-Final-Report.pdf)
- [DEUS Token Contract Audit](https://hashlock.com/wp-content/uploads/2024/10/XMAQUINA-2nd-Smart-Contract-Audit-Report-Final-Report-v2.pdf)

## RCM Protocol

The core smart contracts of RCM Protocol have undergone an independent security assessment conducted by Halborn in September 2026.

The assessment covered the smart contract infrastructure supporting subscriptions, escrow, asset issuance, investor eligibility and settlement.

### Reports

- [RCM Protocol Smart Contract Assessment](https://www.halborn.com/audits/xmaquina/managed-smart-contract-assessment-0e2054)
